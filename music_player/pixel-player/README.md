# PIXEL PLAYER · 像素播放器

一款**像素风格**的本地音乐播放器。所有歌曲内容（封面图、歌名、歌手名）均自动读取音频文件内嵌元数据（ID3），播放器本身不内置任何固定封面、歌名或背景色。

## ✨ 设计规范实现

| 规范 | 实现 |
|------|------|
| 背景层：封面放大铺满 + 高强度模糊 + 降低透明度 | 封面经 canvas 重采样至 240×150 后拉伸铺满全屏（跨环境稳定的高强度模糊），压暗 24%，图层透明度 88%，径向渐变遮罩聚焦中央；**色调纹理完全由封面决定，切歌自动交叉淡化切换** |
| 左侧封面卡片 | 正方形卡片、宽约 1/3、右下方向投影悬浮质感、白色边框，内部显示**原始清晰的封面图**，居中填充 |
| 右侧信息区 | 垂直居中、左对齐：第一行歌名（白色像素字体、大字号）、第二行艺术家（约 1/2 字号） |
| 歌词区 | 右侧居中大号歌词（当前行约 30px、上下行 23px），随播放平滑滚动；利用右侧大面积空间展示，中心与封面卡片对齐；支持同名 `.lrc` 同步歌词，无 `.lrc` 时回退读取内嵌歌词（ID3 USLT），无歌词显示占位 |
| 频谱条 | 底部白色小圆点轨道（全白装饰）+ 叠加**实时音频频谱**（白色竖向细条，高度按 4px 像素格量化，对数频率映射 + 峰值保持，随鼓点/旋律节奏跳动） |
| 进度条 | 频谱下方**独立白色进度条**（可拖动），与频谱轨道分离 |
| 层级关系 | 模糊背景 → 封面卡片（投影）→ 文字 + 歌词 + 频谱条 |

## 🚀 使用方法

1. 打开 `index.html`（需联网加载像素字体 Zpix 与 jsmediatags，之后播放本地文件完全离线）
2. 点击或拖入本地音乐文件（支持多首；可同时拖入**同名 `.lrc` 歌词文件**）
3. 点击封面或「▶ 播放」播放/暂停
4. 快速体验：打开 `index.html#demo` 加载内置示例（示例封面、歌名、歌手、歌词同样全部来自文件内嵌元数据）

## ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| 空格 | 播放 / 暂停 |
| ← / → | 上一首 / 下一首 |
| ↑ / ↓ | 音量 +5% / -5% |
| M | 静音 |
| P | 播放列表开合 |

## 🎛️ 控制说明

- **播放列表**（「列表」按钮或 P 键）：右侧滑出面板，显示全部歌曲，点击切换、✕ 移除单曲、「清空」重置；当前播放项高亮
- **播放模式**：点击「顺序」按钮循环切换 顺序 → 随机 → 单曲循环（记忆上次选择）
- **音量 / 静音**：滑条或 ↑↓ 键调音量，🔊/🔇 或 M 键静音（音量记忆）
- **歌词点击**：点击任意一句歌词直接跳转到对应播放位置

## 🔧 技术要点

- **ID3 解析**：jsmediatags 读取标题/艺术家/内嵌封面（APIC）
- **动态模糊背景**：封面 → 240×150 canvas 重采样（模糊）→ 压暗 → dataURL 铺满背景层；双图层 + opacity 过渡实现切歌交叉淡化
- **频谱**：Web Audio API `AnalyserNode`，白色细条高度按 4px 像素格量化，营造像素风
- **像素字体**：Zpix（中文像素字体，jsdelivr CDN），失败回退等宽字体
- **隐私**：文件全部本地处理（`URL.createObjectURL`），不上传任何服务器
