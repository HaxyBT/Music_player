# Music Player

两个手写的极简音乐播放器，纯 HTML/CSS/JS，打开即可用。

| 目录 | 说明 |
|------|------|
| [`vinyl-player/`](./music_player/vinyl-player/) | 黑胶唱片风格 · 本地上传 + 内嵌封面旋转 + LRC 歌词跟随滚动 |
| [`aerowave/`](./music_player/aerowave/) | AeroWave · 玻璃拟态风格 · 播放列表 + 实时频谱可视化 + 播放模式 |

打开方式：任意静态服务器（如 `python3 -m http.server`）后访问对应 `index.html`。
